# 🏍️ BikerHub — Ride • Connect • Belong

BikerHub is an Android application designed to bring motorcycle enthusiasts together. Riders can discover other bikers, create rides, send join requests, connect with fellow riders, and communicate through chat.

## ✨ Features

- 🔐 User registration and login
- 👤 Rider profiles and profile editing
- 🔎 Explore riders and send connection requests
- 🗺️ Create and discover community rides
- 🤝 Send and manage ride join requests
- 💬 Chat with connected riders
- 🔔 In-app notifications
- ☁️ Firebase-backed user and ride data

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Authentication:** Firebase Authentication
- **Database:** Cloud Firestore
- **Build System:** Gradle

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Add your own Firebase Android configuration file (`google-services.json`) to the `app/` directory.
4. Enable the Firebase services required by the application.
5. Sync Gradle and run the app on an Android device or emulator.

## 🔒 Security Note

Do not commit Firebase configuration files containing sensitive configuration, private API keys, passwords, signing keys, or other secrets. Configure Firebase security rules before deploying the app.
